# Rukayat Portfolio

Standalone Next.js app for Oyewale Rukayat Omotunrayo's portfolio.

Deploy this app separately from the Rugab Dynamic Logistics site.

## Vercel Setup

1. Create a new Vercel project from this repository.
2. Set the project root directory to `apps/rukayat-portfolio`.
3. Use a project name like `rukayat-portfolio`.
4. Deploy.

The portfolio will be served from the free Vercel project URL, for example:

```txt
https://rukayat-portfolio.vercel.app
```
